# EMI Eligibility & Maximum EMI Predictor

## 📌 About
A Machine Learning project that predicts EMI eligibility and estimates the maximum monthly EMI a customer can afford based on financial information.

## 🎯 Objectives
- Predict EMI eligibility.
- Predict maximum affordable EMI.
- Analyze customer financial data.
- Compare Machine Learning models.

## 🛠️ Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- MLflow
- Streamlit

## 🤖 Models Used
### Classification
- Logistic Regression
- Random Forest
- XGBoost

### Regression
- Linear Regression
- Random Forest
- XGBoost

## 📊 Dataset
The dataset contains customer details such as income, expenses, credit score, bank balance, loan amount, and loan tenure.

## 🔄 Workflow
Data Collection → Data Preprocessing → EDA → Model Training → Evaluation → Model Saving → Streamlit Prediction

## 🚀 Application
The Streamlit application allows users to enter financial details and receive:
- EMI Eligibility
- Maximum Monthly EMI
